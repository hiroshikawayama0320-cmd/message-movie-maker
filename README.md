# メッセージムービーメーカー

写真・動画とメッセージを入れるだけで、
「カット → 白紙画面にメッセージ → 次のカット」の動画を作るツールです。

- ブラウザ（パソコンのChrome推奨）だけで動きます。インストールやアカウントは不要です
- 素材はそのパソコンの中だけで処理され、外部に送られません
- 書き出した動画（MP4）はダウンロードフォルダに保存されます

## 使い方
1. 公開ページを開き、パスワードを入力する
2. 左の列に写真・動画を入れ、カットごとにメッセージを書く
3. 右の列でスタイル・色・長さ・BGMを選ぶ
4. 上の「動画を書き出す」→「動画を保存」

## 動画の使う部分を選ぶ（トリミング）・手ぶれ補正
動画のカットの「✂」ボタン（またはサムネイル）を押すと、編集の画面が開きます。
- トリミング：下の帯のつまみを動かすか、開始・終了の秒数を入れる
- 手ぶれ補正：「弱・中・強」を選ぶ（初回だけ揺れの読み取りに数秒〜十数秒かかります）。画面を少し拡大して揺れを打ち消します
最後に「決定」を押してください。

## カットごとの長さ
各カットの「表示（秒）」で、そのカットを見せる秒数を決められます。
- 動画：空欄なら、トリミングした範囲をすべて使います
- 写真：空欄なら「写真（秒）」の長さ。「全体の長さ」を指定したときは、空欄の写真で残りの時間を分け合います
- 最後の画面：「最後の画面」の「表示（秒）」で決めます

## ロゴの大きさ
「最後の画面」の「ロゴの大きさ」のスライダーで、50%〜250%に変えられます。

## iPhoneで撮った動画が読み込めないとき
iPhoneの「設定 > カメラ > フォーマット」を「互換性優先」にして撮影してください。
すでに撮った動画は、MP4（H.264）に変換してから入れてください。
