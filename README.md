# メッセージムービーメーカー

写真・動画とメッセージを入れるだけで、
「カット → 白紙画面にメッセージ → 次のカット」の動画を作るツールです。

- ブラウザ（パソコンのChrome推奨）だけで動きます。インストールやアカウントは不要です
- 素材はそのパソコンの中だけで処理され、外部に送られません
- 書き出した動画（MP4）はダウンロードフォルダに保存されます

## 使い方
1. 公開ページを開き、パスワードを入力する
2. 左の列に写真・動画を入れ、カットごとにメッセージを書く
3. 右の列でスタイル・色・長さ・BGMを選ぶ
4. 上の「動画を書き出す」→「動画を保存」

## 動画の使う部分を選ぶ（トリミング）
動画のカットの「✂」ボタン（またはサムネイル）を押すと、使う範囲を選べます。
下の帯のつまみを動かすか、開始・終了の秒数を入れて「決定」を押してください。

## iPhoneで撮った動画が読み込めないとき
iPhoneの「設定 > カメラ > フォーマット」を「互換性優先」にして撮影してください。
すでに撮った動画は、MP4（H.264）に変換してから入れてください。
